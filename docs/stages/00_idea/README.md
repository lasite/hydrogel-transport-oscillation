# 00 Idea

## Stage Purpose

Capture the scientific idea, its physical intuition, and the uncertainty that must not be erased by later implementation work.

## Human Responsibility

Define the research motivation, central hypothesis, scientific taste, and acceptable claim boundaries.

## AI Responsibility

Preserve the idea without over-formalizing it, point to unresolved assumptions, and avoid converting candidate mechanisms into validated claims.

## Expected Outputs

* Idea log.
* Project brief.
* Open questions.
* Candidate hypotheses.
* Current project-state snapshot.
