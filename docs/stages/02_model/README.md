# 02 Model

## Stage Purpose

Organize candidate model variables, equations, assumptions, and boundary conditions without treating them as validated.

## Human Responsibility

Provide or approve model equations, resolve physical assumptions, and decide which simplifications are acceptable.

## AI Responsibility

Preserve supplied equations, summarize candidate structure, identify undefined quantities, and avoid inventing missing physics.

## Expected Outputs

* Candidate model summary.
* Long derivation source.
* Rendered derivation when available.
* Sanity-check report.
