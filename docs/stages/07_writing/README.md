# 07 Writing

## Stage Purpose

Draft manuscript text only after the model, literature, and evidence boundaries are clear.

## Human Responsibility

Set the argument, decide claim strength, and approve manuscript framing.

## AI Responsibility

Help organize manuscript sections, preserve evidence boundaries, and avoid writing unsupported claims.

## Expected Outputs

* Manuscript outline.
* Evidence-bounded draft sections.
* Claim-evidence matrix updates.
* Citation-backed introduction.
