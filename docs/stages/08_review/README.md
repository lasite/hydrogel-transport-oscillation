# 08 Review

## Stage Purpose

Review the manuscript, evidence chain, figures, and reproducibility before submission preparation.

## Human Responsibility

Judge scientific strength, choose revisions, and approve final claim language.

## AI Responsibility

Audit consistency, map reviewer-style risks, and help prepare revision checklists without inventing evidence.

## Expected Outputs

* Internal review notes.
* Revision checklist.
* Claim-risk audit.
* Reproducibility checklist.
