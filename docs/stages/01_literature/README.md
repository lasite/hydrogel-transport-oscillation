# 01 Literature

## Stage Purpose

Map related work and define the novelty gap without inventing citations or overstating distinctiveness.

## Human Responsibility

Select priority literatures, judge relevance, and decide which distinctions matter scientifically.

## AI Responsibility

Organize search questions, populate a traceable literature matrix only from provided or verified sources, and keep novelty claims provisional.

## Expected Outputs

* Populated literature map.
* Novelty matrix.
* Gap analysis.
* List of mechanisms that appear too close to the proposed idea.
