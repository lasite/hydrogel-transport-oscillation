# 09 Submission

## Stage Purpose

Prepare a final, consistent, reproducible manuscript submission package.

## Human Responsibility

Choose venue, approve final manuscript, and handle submission decisions.

## AI Responsibility

Help check formatting, references, file completeness, and response materials when requested.

## Expected Outputs

* Submission-ready manuscript.
* Supplement.
* Final figures.
* Bibliography.
* Reproducibility notes.
* Cover letter or response materials if needed.
