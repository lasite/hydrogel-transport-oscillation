# Research Stages

This directory makes the project stage gates explicit from initial idea to submission. It does not move existing source-of-truth files; instead, it points to them and records what must be true before a stage can promote work forward.

Stages are human-readable checkpoints for review and promotion decisions. Internal anchors such as `G0`, `G1`, and `G2` are retained only for ordering and traceability.

Current overall state:

* Research Idea Brief (`G0`): complete
* Literature / Novelty Mapping (`G1`): complete
* Model Specification (`G2`): active
* Mechanism Analysis (`G3`): blocked
* Minimal Numerical Verification (`G4`): blocked
* Parameter-Scan Evidence (`G5`): blocked
* Figure Evidence Package (`G6`): blocked
* Manuscript Writing (`G7`): blocked
* Internal Review (`G8`): blocked
* Submission Package (`G9`): blocked

Use `stage_index.md` as the quick map. Use each stage's `gate.md` before treating work as complete or promoting it to the next phase.
