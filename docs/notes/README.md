# Physics Notes

Physics notes are lightweight, physics-first working documents for reasoning that does not change project state.

Use a physics note for derivation sketches, boundary-condition reasoning, physical-intuition checks, limiting-case comparisons, critique of candidate assumptions, and option comparison before opening a Codex task.

Do not use a physics note to change project stage, promote a model, record validated evidence, create production numerical results, or draft manuscript claims.

Use `docs/notes/PHYSICS-NOTE-TEMPLATE.md` for new notes when a note is stored in the repository.
