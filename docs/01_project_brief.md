# Project Brief

Status: exploratory
Confidence: low-to-medium
Model validation: not yet completed

## One-sentence central hypothesis

A non-oscillatory exothermic Arrhenius reaction can become a self-sustained relaxation oscillator when coupled to LCST poroelastic collapse because the collapsed hydrogel skin self-organizes into a transport and reaction-accessibility barrier that reversibly interrupts thermal runaway.

## Core scientific question

单一放热反应与 LCST 水凝胶塌缩耦合后，是否能通过空间输运退化和反应可及性屏障自发产生可逆前沿型自振荡？

## Candidate mechanism

1. 反应放热导致局部温度上升。
2. 温度越过 LCST 后，水凝胶发生局部塌缩。
3. 塌缩区域降低扩散、渗透性或反应可及性。
4. 表层或前沿状屏障削弱反应物供给和热源。
5. 热释放减弱后系统冷却。
6. 凝胶恢复开放状态，反应物重新进入。
7. 系统可能进入可逆前沿型 relaxation oscillation。

## Target claim type

This project aims to establish a mechanism, not merely fit a numerical oscillation.

## Main risk

* 机制可能只是均匀 ODE 热反馈；
* 振荡可能是数值边界效应；
* LCST collapse coupling 可能只改变时间尺度而不形成真正开关；
* 反应可及性屏障可能需要额外假设；
* 线性稳定性可能不能预测非线性吸引子，但必须解释为什么。
